Terminologia:
- Relazione->**Tabella**
- Tupla->**Riga**

### Definizione schema
Uno schema raggruppa tabelle e costrutti. È identificato da un nome di schema e descrittori degli elementi. Ha come elementi tabelle, vincoli, viste, domini e costrutti. Gli schemi possono essere raggruppati in un catalogo

- Il metadato è la descrizione del dato.
- SQL keywords are NOT case sensitive
- Alcuni database richiedono il ; alla fine 

Il [[Definizioni|DBMS]] esegue le istruzioni con un ordine preciso
1. RENAME (`AS`)
2. SELEZIONE (`WHERE`)
3. PROIEZIONE (`SELECT`)
